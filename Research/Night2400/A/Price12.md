# Factor-free quadratic incoming valuation price at `v_Q=100,102`

Assume the exact root-seven prefix of the [packet](README.md). Let `f=v_Q(N)` be 100 or 102, `X=7^12 Q^f`, `D=sigma(Q^f)`, `B=10^2400`, and `c=f-1`. The two fixed components contribute exactly one incoming `Q` (from `sigma(7^12)=Q`, while `sigma(Q^f)=1 mod Q`). Here `D` is coprime to `X`, so `XD | N`. We use no factorization of `D`.

For each nonfixed actual component `r^h`, `h>1`, let `j=v_Q(sigma(r^h))`. The verifier proves that, except for a finite checked loss list, `r^h >= Q^(2j)`. For each exceptional base `r` it retains the largest loss `Q^(2j)/r^h` over a relaxation, and the product of these rational losses is `U`. Using one maximum per base is valid because each prime has just one actual exponent. There is one exceptional base in each replay; neither its primality nor realization of the relaxed exponent is assumed.

**Complete loss search.** All viable `h` satisfy `h+1<Q`. Thus if `r=1 mod Q` the incoming valuation is zero, and for `r != 1 mod Q` the only nonzero cases have `k=ord_Q(r)>1` dividing `h+1`. By LTE, `j=v_Q(r^k-1)` because `Q` does not divide `(h+1)/k`. If `4|k`, the resulting exponent `h=3 mod 4` is impossible in an odd perfect number. Otherwise the conservative minimum is `e=k-1` for `k>2`, and `e=5` for `k=2` (here `h>1` must be odd and `1 mod 4`). We need only `1<=j<=c`. Reject orders with `3^e>B/X` or `3^e>=Q^(2c)`, or above the size-proved exponent bound. For each remaining order find an element of exact order `k` modulo the certified prime `Q`; its unique Hensel lift modulo `Q^(c+1)` generates all roots of exact order `k` at each depth. This follows from the cyclic nonzero group modulo `Q` and uniqueness of each lift (derivative nonzero modulo `Q`). The verifier exhausts primitive powers, all depths, and the only possible cheap odd representative per class: `r^e<Q^(2j)` implies `r<Q^j`, since `e>=2`. A candidate is kept only at exact valuation `j`, when it fits the size cap and it is not ruled out by small divisibility or Fermat. Each filter is necessary for an actual exceptional prime. The representatives used in the size break cannot decrease as the modulus grows: the odd classes are nested.

**Euler partition.** If there is no exponent-one Euler prime, multiply the component prices: `N >= V=X Q^(2c)/U > B`. If the Euler prime `p` has exponent one, write `s=v_Q(p+1)`, where `0<=s<=c`, and `m=Q^s`. Since `p` is odd, `p>=2m-1=L`. Independent incoming pricing gives `N>=V L/m^2`. If that is insufficient and `p` does not divide `D`, then `N>=XDL`; the verifier requires this strict bound. If `p|D`, the odd quotient `D/p` is at most `D/L` and is congruent to `-D mod 2m` since `p=-1 mod 2m`. The verifier tests divisibility on the full remaining progression (and refuses a large window). At 100, incoming price alone excludes 64 windows; the remaining 36 all fail the internal divisor bound. At 102 the corresponding counts are 70 and 32. None needs an interior progression scan after the bound. These tests also cover `s=0` and the entire high-Euler case. Only exact `v_Q` fibers 100 and 102 are claimed, not the root exponent or shard.

The [standard-library implementation](Price12.py) is called only from the exact-prefix [verifier](Verify.py), which proves `Q` prime and binds the scope. It can independently print pricing receipts with `python -I -S -B Research/Night2400/A/Price12.py 100 102`, but packet validation is the authoritative entry point.
