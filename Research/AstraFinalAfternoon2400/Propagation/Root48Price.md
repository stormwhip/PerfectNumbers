## 精确域和 Euler 任意指数

证书验证根 sigma 完整素因子为 `t·29·3529·4733·1074473·13473433`，`σ(t²)` 完整因子为 `61·1965401149·518019223567·600424816906741`，并证实 `617·531983|σ(t^10)`，不猜匿名余块。两锚均为 3 mod 4，故普通。为检验直接活域，从 `v_r(D)` 连续遍历 h，阶段末严格单调尾 `X(D/r^v)r^h>B` 分别为 195、344；每个合法偶指数重新计算固定 sigma、入流和 `XD|N`。禁素数为且仅为 19。

固定前三行写质量 X、输出 `S_k`、剥离全部固定支持后的 `D=∏D_k`，并在目标 `t,r` 算出精确剩余需求。任意 Euler `q^a` 满足 `q≡a≡1 mod4`，`a=4k+1`，有

```
σ(q^a) = (q+1) G(q²,2k),        q^a = q·(q²)^(2k).
```

所以 q 的线性块与其平方底 odd atom 价分别计入，后者在 `k>0` 时完全保留；当 `k=0` 时为 1。令 `i=v_t(q+1),j=v_r(q+1)`，枚举它们在各自精确需求内的全区间。`m=t^i r^j` 给同余 `q≡2m−1 mod4m` 和 `q≥Q=max(5,2m−1)`。普通强迫标签只在它们确定不是这一窗的 q 时才赚取价格及偶次补价；这个筛选也适用于高 Euler 指数。

## 联合定价与两条扣账不等式

两个 odd-atom 目标分别用 6 与 2（f=2）或 10（f=10）。任何实际供应者的有效指标只用目标自身与其 `s−1` 的奇因子；`gcd(t·odd(t−1),r·odd(r−1))=1` 严格验证，因此两个有效指标可相乘而不超长度预算。`t−1=16·7³·572161·1944734959` 的两大素数超过长度上限，t 端非平凡最小阶为 7。r 端权不超过最小非平凡 odd 阶减一；通用 [全提升核](Propagation.py) 扫描完整失价区间，并断言没有超过各自主模数的可能失价底数。`may_be_base` 接受合法 Euler 平方，Fermat 筛绝不用来认证强迫素数。

对每个已认证且非 q 的普通强迫标签 z，枚举所有 `z^g≤B` 的偶 g，取得 `min z^g/(t^(6u)r^(w v))` 及两个单独最大入流。标签积价 G 给 `NU≥XQ t^(6u_rem) r^(w v_rem)G`。若未排除，证明任何 q 都不整除 D：当 `j>0` 时，`r≡3 mod4` 与 `q≡−1 mod r` 通过二次互反保证 r 对 q 为非剩余，故 q 不可整除奇长度 `G(r,h)`；剩余固定输出用完整候选余因子等差级数。`j=0` 时三个输出全部逐项检查。上界用 `B/X`，不用虚假外部性再推更严上界。

只有 q 实际外部时，使用标签偶次补价 F（D 中奇赋值的认证非 Euler 标签之积）得到 `N≥XDQF`。若仍未排除，**不需要** q 的指数为 1：`q∤σ(q^a)`，q 又不在固定输出，因此它必有一个外于固定行的普通发射者 `z^g`。记其双入流 `(a,b)`，`3z^g/2 > Q·t^a r^b`。以支持分区的最大块 M 上界 `z^v_z(D)`，分别得到：

```
3 N M > 2 X D Q² t^a r^b F*
3 N U > 2 X Q² t^a r^b · t^(6(u_rem−a)) r^(w(v_rem−b)) G*.
```

如果 `(a,b)` 某一维超过安全标签的最大入流，发射者与标签集合不交，用 `F*=F,G*=G`；否则两个都置 1。第二个不等式对除发射者外的所有 odd atoms 定价，**包括高次 Euler 的 q² atom**。每个 `(a,b)` 单独逐项检查，两个不等式是备选矛盾，不叠加。边界核心为精确有理数和整数量价。
