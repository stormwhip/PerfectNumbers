# 独立验收清单 — 冻结主线 495c59f55456a70994ce7848487e0c4e262c1984

1. **命题与来源。** 固定 `N≤10^2400`、`σ(N)=2N`、奇数、规范根序 `(19,7,11,31,13,3,5,17)` 及前序根禁素。列出每个精确赋值（不等于整除）、Euler 状态、证明/数据及冻结字节哈希。必须凭 `σ(N)=2N`、已认证素性和未被已知部件耗尽的赋值证明子枢轴强制存在。圆分余块未分解时，只用实际已证性质，禁止按“未找到因子”推素性、平方自由或不存在供应。
2. **分支与尾部。** 独立从必要条件枚举整段、包括零值（若枢轴未强制）、Euler 合法奇指数和普通偶指数。输出活值的集合，不仅是个数；对子树须逐个覆盖同一前缀下的每个活值。首个尺寸严格超限 `>B` 及其以后单调；如果更早停止，必须说明实际剪枝量的单调性及前提如何持续，等号不剪。从 `X·D` 续分时，以 `lcm` 或商精确扣掉和枢轴的重叠，不能把已付的幂再乘。
3. **Hensel / CRT。** 对每个真实有效阶、LTE 增量、目标零供应轴及共享阶组合给出覆盖论证；验证阶因子和根数、根是否为全部解或保守超集。若正亏格 `b^(d·h)<s^(a·z)`，仅在 `a≤d·h` 时不借助额外界就推出 `b<s^z`；截断层需使用需求上限和真实（可截断）赋值。超过此权重须证完整非最小提升，或使用独立上界把整项缩到模数以下。CRT 同理要证明正亏格区间小于合模，不能只验所列代表。核对奇性、合数排除及 Euler 平方原子。PR #11 反例：`b=83=7+4·19`，`Φ3(b)=6973=19·367`，`83²<19⁶`；它否定代表覆尽推论，不是完整分支的反例。
4. **Euler 与价格重叠。** 穷尽已锁定 / 未锁定、内 / 外 Euler、线性 / 更高指数、`v_s(q+1)=0` 边界及可能的普通发射源；未锁定时 `G(q,4k+1)=(q+1)G(q²,2k)`，只付一次 `q` 并保留合法平方原子。若外 Euler 需普通供应，先证 q 不来自固定输出、也不是自身来源；发射源必须与已固定位点不同，并审计与 `D` 的 `gcd`。两条分别对 `N` 的严格下界相乘是约束 `N²`，不是 `N`。同一 prime-power 的多目标估价只有在互素有效长度、明确指数预算分配或联合定价下可合；两张单价表本身不足。多路线同一底取覆盖上确界，不把同一个实际根当两份大小。
5. **终端算术、复跑、故障。** 对整数/有理比较的每个端点和严格不等式做独立复算；同时重建“哪些端点必须检查”的集合。故障测试优先删除真活项、改 tail/阶/LTE、引入未列 Euler 分支、删非最小根、同一源双计、将条件记录标成完整。两种实现若仅复算同一表、剪枝或候选集，不构成覆盖证明。弃用 `-O`，不得改历史哈希断言绕过 CRLF；以冻结 Git blob 的原始字节复跑。
6. **投影。** 对每项分别标候选 / 已证局部 / 完整精确键。在绑定全部活分支及历史依赖之前不删除整键；独立从当前 `ShardRemainders` 对经认可完整键做逐片差集，并重建反向映射，核对一个键可能出现在多个分片、一个分片可能含多个键。条件叶与条件父纤维同时上账时记录包含关系，不累加当成独立进展。局部证书、全仓历史冷重放和 72 小时验收是三个不同命题。
