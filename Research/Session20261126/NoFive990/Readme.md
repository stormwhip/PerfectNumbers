# 规范根为 3、指数 990 的无五子域

这是**条件证明**，并非排除 $(3,990)$。在原规范根三的禁素表下，如果 $N$ 为奇完全数、$N\le10^{2400}$ 且 $3^{990}\parallel N$，则 $5\mid N$。已有 Euler 分支及 $5\nmid N$ 的 12 类支持的两种来源分别处理，$5\mid N$ 的其余支持没有因此被排除。

[源程序、证书和归档内逐文件清单](Partial.zip)的 SHA-256：`71d62c060d6a9e2c7c043cb1c94f90681cb1d45bc3ae5caeeea836e5a4f6474b`。将其解压至单独目录，先编译、运行 `Base/Trial990.cpp`（C++17、`unsigned __int128`），确认 `R=9092464640001` 的确定性筛通过；再运行 `python -I -S -B NoFive990.py REPO`。`REPO` 指整个仓库的绝对路径。最弱叶必须通过严格未舍入不等式，不是只看 floor=2400。独立条件验收还包括 `AllRegions.py` 所列的其他部分子域；即使同一实际指数在多种来源分支出现，也不能增加全指数计数。

必要性例证：外部叶 0 的 9800 个潜在来源支撑原子中，有一项不能由粗对偶区间排除。对该 82 位数作完整因子分解，验证三个素数及其各自不可能作为来源（包含两条大素数证书），即可补回唯一一项。有效的整域证明仍需覆盖全部 $5\mid N$ 支撑和来源。
