# 根 13 指数 568：匿名分圆块的价格与混合递归

此包的完整验收**需要 Python 3.11+ 与 `python-flint==0.9.0`**。该库只执行精确整数/模多项式乘积、求值与 gcd，不把可能素数测试的成功当作结论。可在隔离的 Python 环境安装该版本，或将预装的库目录传给 `PERFECTNUMBERS_FLINT_PATH`。不需要外部因子数据库、网络查询或商业软件。

```sh
python -I -B Research/Session20261126/Anon568/Check.py
```

[离线源程序与证书](Proof.zip)附[逐文件哈希清单](Manifest.json)。[入口](Check.py)核对归档所有成员后在临时目录重建根幂、2,404 个精确状态及所有终端；六种特殊情况要从头核对全部相关进程中的素因子范围和一次/平方因子格区间，不能用缩短的 `quick` 测试替代 `all`。其余终端分别为 403 个分割节点、1,797 个普通尺寸叶、190 个固定 Euler 叶、8 个丰度叶。

关键步骤：每个匿名块先获合数证据，然后排除所有可能的素数幂，才能得出至少两个**不同**素因子。程序只给确实存在的不同素数分别收取允许的净成本，对可能的唯一 Euler 位置、不同来源间的重叠以及逐精确来源的固定赋值预算保留必要退款。与外部 Euler 来源相容的平方因子通过短多项式逐区间排除；必要的内部 Euler 区间独立检查。结果仅适用于规范根 13 的精确指数 568；不得提升至别的指数，也不排除八根之外的素因子。详尽推导保存在归档内的 `Recursive/Anon568/`。
