# Recursive supply cuts at arbitrary fixed prime powers

The root-level goal and conditional domain are identical to those in the parent SupplyForest release. The new certificate type replaces the single fixed pivot by a checked recursive partition of **actual exponents**. A complete packet contains its own assigned forests, decision tree and primality chains. Use `python -I -S -B Domain.py path/to/Research Recursive7x856.json.gz`; the numerical checker imports the parent `VerifyCut.py`, not discovery scripts or external packages. The enforced tree, not the number of visited discovery cells, establishes completeness.

For a hypothetical odd perfect number, let the fixed odd primes and exact exponents on a path be `F={(p,e),(t1,f1),…}`. Put `X=prod t^f`, `H=prod odd(σ(t^f))`, `C=coprimePart(H,X)`. Distinct fixed components imply that `H|N`; then `X C|N`. Also `v_t(H)<=f` at every fixed prime, and if `od` of the fixed exponents are odd, `od<=1` and `H(1+od)<=2X` by multiplicativity and monotonicity of abundancy. The latter equality factor correctly reflects that an Euler prime and exponent are both 1 modulo 4, so its divisor sum has 2-adic order exactly one. All forbidden roots must avoid all seed sums.

Every internal node supplies a certified odd prime `z|C`, never a previously fixed prime. Its exponent in N is `g>=v_z(C)=h`. For each legal actual `g`, if `X (C/z^h) z^g>B` all larger `g` are impossible. Otherwise attach the exact seed `z^g`, checking the fixed valuations, abundancy, size and forbidden divisors anew. Each branch surviving these *necessary* screens requires a child. The domain verifier reconstructs stage exponents from scratch, verifies that every branch is represented, and rejects any unreachable state. A node is either a splitter or a terminal forest, never both.

The terminal primality, forest ownership and private-remainder inequalities are the same as in the sibling Breakpoint release, with these adjustments. The ordinary blanket `U` pays all ordinary deficits once. The valuation-ledger base is `p^((k+1)e)/U` multiplied by every fixed nonroot premium `max(1,t^f/p^(k v_p(σ(t^f))))`. For a fixed Euler-one location replace its own premium by the **unclipped** ratio, retaining the premiums of the other fixed components. For fixed high Euler use the universal `D` and retain all premiums. An already fixed Euler forces every active forest exponent to be even. In the exterior Euler-one branch, if `q|H` then `q|A` or `q` divides the divisor sum of some individual other fixed component. Exclude the first possibility by quadratic reciprocity and check the cofactor progression for **each** other component separately before multiplying by the exterior lower bound. Do not assume the product `H` alone lies in a restrictive class. In this branch `q=-1 mod p` and no fixed label is possible. The private-emitter coupon still occurs at most once, globally, since `q||N`.

The verifier recomputes all root loads from `C`, never from live factors. The size base is `X C/prod(root load powers)`; private remainders are stripped of all primes in `X`, `C` and owner labels. Raise the mass ledger to `k-1` before multiplying by the valuation ledger. The remaining recursion and treatment of tails agree with the earlier exact pivot theorem. Source: `Domain.py` partitions and checks the decision graph; `VerifyMulti.py` provides an independently coded location-based dynamic program. All final decisions use exact rational/integer comparisons and deterministic primality-chain checks.
