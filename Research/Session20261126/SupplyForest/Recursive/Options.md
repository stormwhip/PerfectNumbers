# Optional exact fixed-budget refinements

`fixedbudget: true` excludes a terminal forest trial exponent `g` at active `z` if the odd part of `σ(z^g)` alone demands more of any fixed prime `t` than remains available. With `H=prod odd(σ(t^f))` over all exact seeds (including the original root), actual perfectness requires `v_t(H)+v_t(σ(z^g)) <= f`. The implementation tests divisibility by `t^(f-v_t(H)+1)`. This is only a necessary condition and may be applied independently at different labels; ignoring combined excesses weakens the proof. Global cutoff bounds still consider unrestricted exponents and hence remain conservative. If no admissible exponent has yet occurred (a whole parity class can be forbidden), a monotone tail already above `10^12000` can conservatively return that finite lower bound. For an Euler trial, `(z+1)/2` divides every odd part of `σ(z^g)` for `g=1 mod 4`; thus a fixed-budget contradiction on this factor rules out that entire parity class. Exactly seven leaves of the 11×522 candidate use this option; all seven revert from `mixed` success to failure when that local check is disabled.

`abundance: true` additionally checks whether forced primes with their minimum admissible parity already make abundancy exceed two. `σ(z^f)/z^f` is increasing in `f` so minimum exponents are conservative. Use at most one Euler coupon across all roots (or none if used by a fixed prime). Forest roots, even if disconnected after conditional re-rooting, are verified divisors of the current seed product.

`sourceforest`, when present, explicitly excludes an Euler-one prime from each nonroot fixed divisor sum separately. At the chosen full valuation threshold `Y=p^cut`, put `Q=2Y-1`. For each residual block `L=coprimePart(σ(t^f),X)`, let `u=L·Q^(-1) mod 4Y`. Then a possible `q|L` must satisfy `Q<=q<=L/u` and `q≡Q mod 4Y`. The verifier derives these bounds from the current fixed seeds and requires a contiguous list of archived integer lattice leaves for each block; if the interval is empty the list must be empty. In the unique 11×420 internal-emitter obstruction one nonempty interval suffices; this is a conditional lattice inequality, not a claim to know a factorization.

`rock: n`, when present, rebuilds residual cyclotomic blocks. Intersect each `Φ_h(t)` with the unknown cofactor `C0` (all assigned roots stripped); discard all shared prime powers by iterative gcd with other blocks, with the complementary cofactor, and with `h`. What remains is pairwise coprime and contains **complete C0 valuations**. All its prime divisors are `1 mod lcm(2,h)`. Failure of division by the first n integers in the progression (inclusive upon finding a divisor) gives a lower bound L. A nonsquare block requires an extra `L` factor in mass if it does not contain the Euler prime. A block whose residue modulo p lies outside the odd-order subgroup contains an ordinary nonprovider, giving an extra `L²` in valuation when it cannot contain Euler. For unknown Euler location, waive the largest individual block charge separately per ledger; when interior to the fixed seeds or active labels no residual block contains Euler, and when the exterior mixed calculation has excluded Euler from every seed sum all blocks are available. These are independent powers of the same inequality, not additional coprime factors between ledgers. `RoughVerify.py` recomputes the entire arithmetic and insists on the exact coprimality conditions. No term is credited based on plausible squarefreeness or an unfactored probable prime.
