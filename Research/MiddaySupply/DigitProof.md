# Batched emitter digit: second-order p-adic cofactor intervals

Let ordinary source r^f have exact supply b=v_p(σ_f(r))>0, p∤f+1, and emit the external Euler prime q of exponent one, with q≡−1 mod p^s, s>0. Assume a proven base interval [lo,hi], q≥Q, and r^c|C for the matching cyclotomic block. Put H=p^b, m=p^min(s,b). The cofactor w=σ_f(r)/(Hq) satisfies 1≤w≤W=floor(σ_f(hi)/(HQ)). It follows that σ_f(r)/H≡−w mod m. When W≥m do not prune. Otherwise use the *entire* range of w at once.

For each base lift r=r0+Tk in the box (T is the CRT modulus, divisible by H), Taylor expansion of the integer geometric sum gives exactly

`σ_f(r)/H ≡ σ_f(r0)/H + σ'_f(r0)(T/H)k (mod m)`.

Higher terms vanish since H*m divides T². Equivalently, the negative of the affine residue must lie in `[1,W]`. Compute the number of successes among `0≤k<n` by differences of Euclidean floor sums. When zero the whole box is excluded, irrespective of how wide the integer r range was. For a small positive count, binary range subdivision recovers every possible base for the actual test `C mod r^c=0`. More than the count cap is UNKNOWN; no proof from stopping. This includes b positive singular mod-p cases only via no-prune fallback. All prior cost, order, balanced gap and prime guard requirements remain in force.

Two implementations use different signs and arithmetic. Discovery computes σ and σ′ via (r−1) inverse at a nontrivial Teich root, signed floor differences on the complementary residue; separate replay computes value and derivative together via Horner and counts crossings by the archived transposed floor-sum. Both construct the necessary interval from actual integer budgets; neither assumes the residual or candidate base prime. The base cost, known-source and external-source predicates come from the frozen Nov25 and NightUniformReview modules. No program in this release downloads data or runs LLL. Tests compare 4,000 signed floor sums to literal finite sums and retain 204 synthetic true-divisor boxes.

For intermediate counts the affine class is a translate of the lattice generated by `(1,a),(0,m)`. Integer Gauss reduction in the scaled rectangle metric has determinant ±m and changes no points. The verifier enumerates the complete determinant-bounded range of the second coordinate, then intersects the two linear inequalities on the first coordinate; it checks cardinality against the floor count before accepting an empty divisor set. This finite enumeration does not assume that a candidate is prime. The exterior source uses the ordinary expense only once, with `r∤A`: `r^f>2Qp^b/3`, `r^f≤B/(MQ)`, `r^(2f)<Bp^b/(p^e A)`. For narrow exterior base ranges omit only numbers explicitly shown ineligible; wide ranges with any admissible digit remain UNKNOWN.

At `p=11,e=718,f=4`, `q|σ_4(r)` and q>5 imply `ord_q(r)=5`: `r=1 mod q` would give `q|5`. Therefore q≡1 mod5. For a finite prefix of k in q=2·11^s·k−1, sieve composites, inadmissible Euler multipliers and this order congruence; passing a Fermat test never proves primality. In the specific `c=2` branch of the four hardest s, `r²|C` gives `r≤isqrt(C)<q`. Under the hypothesis that q is prime the four nonidentity fifth roots modulo q are exactly x,x²,x³,x⁴ when `x=a^((q−1)/5) mod q` is nonidentity. A failed `x^5=1` proves q composite. For each surviving q, all four possible positive r below q can thus be checked directly against C; if no primitive x is found from the finite witness bases no denial is made. The lower q bound after these checks is applied **only** to this source class. The source-specific order/prefix statements and the baseline guards are shared proved lemmas between the two replay implementations; neither is an independent factorization claim.
