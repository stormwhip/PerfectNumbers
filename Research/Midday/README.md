## 方法与计费原理

1. **全局候选边池，按实际指数激活。** 从 32,889 个潜在发射素数提取 162,693 条历史候选边，放弃历史图的树根、层次和所有者。重新用实际指数 `e` 的 `A=σ(p^e)` 建立强制根，检查每个候选根整除 `A`。在每轮最低成本反例中只查看当前精确的 `(z,f)`，在 `σ(z^f)` 中查找已有边、分圆块或定向分解产生的因子。没有被当前精确几何和触发的边不能为本分支提供任何额外成本。来自在线表、缓存或筛法的数在独立素性验证以前只作为提示。因子表不需要可信或完整。
2. **Euler 定点修补。** 在给定图上同时计算无 Euler 的成本和在指定标签处允许 Euler 的成本。多个图可分别处理不同的 Euler 类型：对每个类型先取有效下界的最大值，再对类型取最小值；顺序不能交换。发现阶段可将唯一薄弱的 Euler 素数移至额外强制根，只搜索这一分支。若有得出的图在撤去这一额外假设后已能成功，用普通的穷尽式森林验收，不为 Euler 子类额外计数。这样把 `(19,168)` 与 `(19,442)` 的薄弱特殊位置分别定位至 `133338869` 和 `8861`；两份最终证书均不依赖定点假设。
3. **森林为何给真下界。** 设 `K` 为 `A` 的已认证素因子子集，`T` 为具有唯一父亲的附加候选素数。令 `U=pA∏_{t∈T}t`。对于实际触发的 `z^f || N`，令 `D_z` 为 `odd(σ(z^f))` 去净 `U` 的全部素支持后的因子。因为所有发射者是互不相同的精确素幂，`∏D_z | N`：乘积先整除 `σ(N)=2N`，再利用它为奇数。**不要求不同 `D_z` 互素**。它们全部与 `U` 互素，所以还可以乘上 `p^e`、`A` 未列出的部分以及各已激活标签的素幂。每个 `z` 的指数要支付至少其实际传入的重数；为了得到保守下界只取唯一父节点贡献即可。对子树分别取无例外/至多一个 Euler 例外的最低整数积。分枝中普通幂为偶数；Euler 为 `z≡f≡1 mod 4`。只可把一枚优惠给予一个孩子或根本不用。未枚举尾部只计单调的素幂，不预算未来发射。
4. **跨指数的严格边界。** 若 `e+1 | f+1`，`A | σ(p^f)`。固定种子原来的 `A,U` 和成本，不靠 `σ(p^f)` 的未知素支持，可以复用只依赖根分圆整除的森林。精确赋值配额、前缀树及条件支持包不得自动提升。完整片仅在它的**全部**剩余指数都有证书时计入。
