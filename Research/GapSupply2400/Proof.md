# 间隙与赋值供给的联合证书（根 3、5）

**结果。** 从 `22dd9bd` 的 1,045 个开放分片出发，在根 3 类完整排除实际指数 1296、1300、1302、1308、1312、1330。三个完整分片 `P3_I00212`、`P3_I00213`、`P3_I00214` 各以其中一个指数为代表；其余更高合法指数至少是 `3(d+1)−1`，已由 `3^e σ(3^e)>B` 排除。总数 2,030 闭合、1,042 开放，不是全局证明。根 5 本轮没有完整排除。先前部分区间实验不作为证书输入。

从仓库根目录复跑（Python 3.10+ 标准库，不加 `-O`）：

```sh
python Research/GapSupply2400/CheckShards.py
python Research/GapSupply2400/Independent.py
python Research/GapSupply2400/Lift.py --steps 100000 --output replay.json
```

前两个命令独立于生成器；核心算术通过 16 个二次幂价格门槛给出更弱的整数下界，不调用生成器或旧数学验证器。第一条直接核验三个分片的所有合法指数，第二条另外从历史已验收清单重算分片差分。最后一个命令在事先指定的 51 个高指数上生成[扫描记录](LiftDeep.json)，以十万等差候选为每块扫描上限。首次基础版（不作平方筛）在 533 个根 3、5 输入中只完整排除 (3,1330)。

目标是在 `N≤B=10^2400` 的假设下排除根类中的实际指数，而非证明所有奇完全数的下界。根序、早于 p 的禁素数及旧核验见[上游区间证明](../../Documentation/ResearchReport2400.md)。记 `p^e || N`，e 正偶，Euler 项 `q^a`。`a≥5` 和一部分 `a=1` 的分支沿用已签入的 EulerSourceIntervals 验证器。后文假设 `a=1, s=v_p(q+1)>0, Y=p^s, Q=2Y−1, P=p^(e+1), A=(P−1)/(p−1), δ=P/Y`。要求 `q∤A`（p=3 或 p=5 且 2s>e）。因为 `A | N` 而 `q | σ(N)`，存在 `r^f || N`，不同于 p 和 q，`q | σ(r^f)`。设 `c=v_r(A), g=f−c≥0, t=r^g`。

## 1. 来源不支付根赋值

若 `f+1=p^j m`，p 不整除 m；`p∤q−1`。若 r≠1 mod q，则其阶整除 m；若 r=1 mod q，则 q 整除 m。两者均给出 `q | σ(r^(m−1))`，于是 `r^f>(2q/3)^(p^j)`。当 `2^p p^e Q^(p+1)≥3^p B`，有 j≥1 将导致 `p^e q r^f>B`。因此 j=0。由于 p=3 或 5，r mod p 的非平凡阶不可能整除奇数 f+1；若 r≡1 mod p 则 LTE 给 `v_p(σ(r^f))=v_p(f+1)`。所以来源 r 贡献零单位，全部 `k=e−s` 个单位只能由其余偶幂提供。

## 2. 来源在 A 之外的尺寸

记 `H=max(1,P/q)`。有 `t>Y/[H(δ+4)]`。若 c=0 直接用 `t>2q/3`。否则置 `U=(P−1)/r^c, w=σ(r^f)/q`，令

```
D=Uw(r−1)−U−rt,  E=Uw+Uσ(r^(c−1))−σ(r^g).
```

`Ur^c=P−1, qw(r−1)=r^(f+1)−1` 给出 `Y|D`。`r^c E=P(w+σ(r^(c−1)))−w(q+1)` 给出 `Y|E`。模偶数 r−1，`D≡−P`，非零。若 E=0，后一恒等式要求 `s+v_p(w)≥e+1`，但 `σ(N)=2N` 给出 `s+v_p(w)≤e`。因此 `|D|,|E|≥Y`。且 `U≤Uw< Htr/(r−1)≤3Ht/2`。

若 `r−1<δ+2`，D 正时 `D<Htr`，D 负时 `−D<(3H/2+r)t`，都小于 `(δ+4)Ht`。若 `r−1≥δ+2`，E 负时 `−E<3t/2`，E 正时 `Y≤E<3Ht/2+δY/(δ+2)`。均得所称间隙。这里使用[指标容量文档](../IndicatorCapacity/Readme.md)的已有同余式，改变了两式切换点。

## 3. 其它供应素幂在 A 之外的尺寸

对每个非来源供应素数 z，有 `z≡1 mod p`。若 `z^d || A`（容许 d=0），要提供第 j 个单位，其增量成本至少为 `z^[max(d,p^j−1)−max(d,p^(j−1)−1)]`。试除至 `T=100000`，完全核对 `z≤T` 的 d。若第 j 级的几何和含禁素因子，则第 j 级及以上永远不能用。对小素数保留价格 ≤T 的边际因子；其它付费单位一律允许以 T+1 购买。保留虚拟供应者或没有被实际选中的小素数，只会降低下界。

对 `z>T` 未知的供应素数，令 b 为已由其 d 免费承担的单位数，即 `p^b−1≤d` 的最大整数。`d≥(p−1)b`。把 A 除去所有小素数得 V，所以所有大素数共免费的单位数至多 `G=floor(log_{(T+1)^(p−1)} V)`。部分免费并非全免：每个未全免单位的增量指数至少 1，仍须支付 T+1。令 `C(i)` 为最便宜 i 个保留或虚拟单位价格的乘积（含小素数免费项，`C(0)=1`）。则除去 `p^e q A t` 后的尺寸至少是 `C(max(0,k−G))`。这是相乘的关键：r 没有单位；任何其它 z 只对超出 `v_z(A)` 的幂计价。

可进一步按 `h|e+1, h>1` 分开计算 `Φ_h(p)` 的大素数免费额度。因 `h≤T<z`，z 不整除 h；模 z 的 `X^h−1` 无重根，故 `z|Φ_h(p)` 给出 `ord_z(p)=h`，尤其 z 不能同时在两个块中。h 为奇数，z 奇，故 `z≡1 mod lcm(2h,p)`（最后的 mod p 来自供应者条件）。有一个免费单位就要求 `z^(p−1)` 整除该块，特别是平方整除。沿这个等差数列从 T 以上扫描，连合数也试，遇第一项平方整除即停止；若用尽步数则停在首个未测值。由此获得可能免费素数的下界 L_h，将各块 `floor(log_{L_h^(p−1)} V_h)` 相加即可。未知的高位部分无须分解。已知非供应素数若在 A 中出现奇次，应补为偶次；扣掉最大的一笔（可能属于 r）后，其余补价乘积记作 J。

综上，利用 `q≥Q` 和 `q²/max(P,q)` 的单调性，证书只需检查

```
p^e A Q² Y · C(max(0,e−s−G)) · J ≥ B max(P,Q) (δ+4).
```

间隙为严格下界，等号也排除。G、C、J 的取整和最后的比较均为整数；不用浮点数、概率素性测试或外部因子库。与 [Ochem–Zelinsky, arXiv:2607.19746](https://arxiv.org/html/2607.19746v1) 的关系是用已禁止的因子限制成分的供应能力；此证书不依赖该文的计算树，也不假设只有一个高偶指数。
