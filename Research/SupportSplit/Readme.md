# 八根支持分割证据

**证据等级。** 条件支持排除。登记键为 $(p,e,H)$，其中 $H$ 是八根中恰好整除 $N$ 的集合。新增九项是相对本次基础筛的差量。全部 244 个实际指数仍有开放支持。

输入为冻结的 [Midday/Delta.json](../Midday/Delta.json)（Git blob `3a7b6812aafed3dddd228c34ed9575324d242887`），其中包含 204 个开放分片。数学推导见[总证明](../../Documentation/Proof2400.md#晚间支持集合分割条件结果)。单根支持与禁素的精确解释、丰度及尺寸界、$15\mid e+1$ 的根十九限制均见该节。
