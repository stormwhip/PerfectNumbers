# 下一步计划

以[更新后的待证账本](../Research/Session20261126/Delta.json)中的 117 个规范分片、135 个不同实际指数为任务全集。单指数任务从 `remaining_shards` 中筛选 `len(remaining_actuals)==1`；不要从历史示例重新创建已结任务。

1. **根三高指数。** [1162 联合计价](../Research/Session20261126/Joint/README.md)的 E3a/E3b 两组均已有 42/42 叶；保留其回归测试。向 1108、990、970、856 移植时逐一重建基础、源位置、奇重数补价和适用叶，不能迁移 1162 的叶数或数值。其次尝试逐素数限制可能同时流入的最大重数，使完全平方补价只用于确实独占的支撑。
2. **联合供给与尺寸。** 对冻结前沿各根重新计算 [供给森林](../Research/Session20261126/SupplyForest/Proof.md) 的高 Euler 界、外部一次幂窗口和内部 Euler 素数窗口；仅两侧窗口实际重叠或相接且全域通过才签发完整指数。
3. **剩余小指数。** 普通森林无新孩子时，固定强迫素数的实际指数，重建余项及父子关系；无论前缀多长，都必须排除尾段。多级树必须为每个相容指数提供后继，不得跳过困难叶。首选只剩一两个未验子分支的枢轴。
4. **支持与全局替代。** 合并[条件排除](../Research/Session20261126/Support/Readme.md)与[全局命中定理](../Research/Session20261126/GlobalSupport/Readme.md)。对缺 3、5、19 而必含 7、11、13、17、23、29 的补侧重建对偶；若不能过线，核查最便宜的精确指数选项有无可认证新素因子。精确支持与 Euler 位置只计条件状态，直至一对 $(p,e)$ 的所有可能性均被排除。
5. **最终验收。** 全量证明仍缺账本中每个实际指数的排除。即使所有行闭合，还需在固定快照独立重放历史基线、八根互素类及新增证明的整套依赖，实测时间、内存和中断恢复。见[形式化研究问题](ResearchProblems2400.md)。
