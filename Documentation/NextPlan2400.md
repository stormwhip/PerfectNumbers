# 下一步计划

以[冻结待证账本](../Research/Midday/Delta.json)中的 204 个规范分片、244 个不同实际指数为任务全集。优先处理能立即闭合分片的实际指数，按候选的证书成本排序。

0. **根 3 的候选证书。** 优先修补 `P3_I00193` 的联合重数计价、余块分配及对偶，重放全体 42 个叶；当前最弱叶保守重算为 2399.9768082683。[审计](../Research/P3I00193Review/Readme.md)。
1. **单指数分片。** 对最弱的合法指数选项分解其精确圆分余因子，重建森林并复核 Euler 位置与指数尾。各根可用的单指数样本见下表。
2. **共享圆分指标。** 对 `P19_I00000` 的 11 个待证指数，均有 $3\mid e+1$。用 $\sigma(19^2)$ 的公共因子重建森林，逐一验证新增计价与实际指数 $e$ 的相容性。根 $3$ 的 $e=856,970,990,1108,1162$ 优先尝试可认证的来源因子和按赋值分割。
3. **穷尽支持。** 将 [SupportSplit](../Research/SupportSplit/Readme.md) 剩余的 $H$ 作为森林的强制根与禁素输入。$(19,14)$ 和 $(19,44)$ 各余八种 $H$。$(31,8)$ 可复用已排除的 $H=\{3,5,13,31\}$ 子域。每个 $(p,e)$ 的合法支持并集全覆盖后方能登记。
4. **验收与计时。** 先固定并核验八根互素类和全部 3,072 个规范分片的证书，再在同一机器记录发现与复验耗时、峰值内存和恢复结果。72 小时是端到端验收目标。
