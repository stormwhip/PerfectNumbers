# 10^2400 下一步计划

本轮验收后有 **406** 个规范分片、**511** 个不同实际指数开放，其中 **365** 片只剩一个实际指数。待证目标以[逐片清单](../Research/Nov25/Delta.json)为准。优先从最弱的精确发射源做定向分圆分解，再重新分配森林所有者。首批可试 `(7,786)`、`(31,316)`。低指数的支持分支见[本轮研究收尾](../Research/Nov25/Closeout.md#下一步)。

1. **优先完整单指数分片。** 对候选 (p,e) 同时记录它即将关闭的分片数、试除库内可认证因子、过往实际节点及慢证书成本。失败时保留第一个未解分支的完整假设；预算耗尽不签发。
2. **静态森林跨指数。** 对固定奇指数指标 h 的分圆因子复用同一森林；对 e+1 为 h 的倍数只搬运已经证明和根精确指数无关的成本。目标树过强时，试将弱种子的 p 幂差与去重后的 σ 比值联合。离散支持辅助根须单独挂上对应的终端前置证明。无条件森林不等于有额外根前提的森林。
3. **用三根门槛缩小整个子类。** 三根互素已排；规范类若原已禁 7，则整个未解树可先分“3或5必有”。尝试两子域的有向整数终端对偶和带附加根的森林。在未知因子过大时先用有界余因子/平方核证书；不要把合数暂时算成素因子。研究较小命中集可先给出完整指数尾和有限例外，而非声称整类已闭。
4. **最后再验 72 小时目标。** 开放量仅为按计数的剩余，不是时间预报。只有原根互素类和 3,072 项全部在固定机器独立验收，才能称全局证毕。应分别记录发现耗时、固定证明输入的重放耗时、峰值内存及中断恢复。
