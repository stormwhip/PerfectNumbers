# 10^2400 下一步计划

以[当前状态](CurrentStatus2400.md)和[逐项剩余账本](../Research/Midday/Delta.json)选目标；已报过的窗口和概率素因子不可移入净增。

1. **优先完整单指数分片。** 对候选 (p,e) 同时记录它即将关闭的分片数、试除库内可认证因子、过往实际节点及慢证书成本。失败时保留第一个未解分支的完整假设；预算耗尽不签发。
2. **静态森林跨指数。** 对固定奇指数指标 h 的分圆因子复用同一森林；对 e+1 为 h 的倍数只搬运已经证明和根精确指数无关的成本。目标树过强时，试将弱种子的 p 幂差与去重后的 σ 比值联合。离散支持辅助根须单独挂上对应的终端前置证明。无条件森林不等于有额外根前提的森林。
3. **用三根门槛缩小整个子类。** 若分片已禁 7、11、13 中的任意一个，则 3 或 5 必有。若 3、5 均缺席，可在尺寸和丰度模型中计入 7、11、13 的强制支持。可结合带附加根的森林与有向整数对偶。在未知因子过大时先用有界余因子/平方核证书；不要把合数暂时算成素因子。研究较小命中集可先给出完整指数尾和有限例外，而非声称整类已闭。
4. **最后再验 72 小时目标。** 开放量仅为按计数的剩余，不是时间预报。只有原根互素类和 3,072 项全部在固定机器独立验收，才能称全局证毕。应分别记录发现耗时、固定证明输入的重放耗时、峰值内存及中断恢复。

批量目标可从根 19 的 P19_I00000 入手。它的 11 个待证指数均满足 $3\mid e+1$，适合检验同一组圆分因子能否支撑全族下界。根 3 的 856、970、990、1108、1162 缺少可认证的大强制素因子，可先将来源按赋值和支持分案。
