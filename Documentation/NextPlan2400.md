# 10^2400 下一步计划

当前清单有 498 个开放分片，涉及 719 个不同的 `(根,实际指数)`；428 个分片只剩一个实际指数。下一轮以[机器清单](../Research/NightMerge/Audit.json)为准。下面编号计划保留其 880 片起始基线与历史优先项，已出证的项目不再排队。

1. **先做单指数分片。** 按剩余指数数和预计复验成本调度。根 7 有 132 个单指数分片，根 3 有 122 个。五个较大根先套用乘法阶禁指数、已知因子最小合法幂及多锚点树。根 11 的 P11_I00061 只差 `e=306`，已有因子树线索，先补 108 位与 182 位两个候选素因子的 ECPP 链，再离线验整除、树叶和分片映射。该项目前仍为开放。[两个因子的定位摘要与搜索参数](https://github.com/stormwhip/PerfectNumbers/blob/ea08da38e38ab3309da4360ea2bb60ecb616a025/Research/EveningMerge/NextCandidate.md)。
2. **并行试根 3、5 的批量区间。** 对根 3 的 153 个分片和根 5 的 77 个分片，复用同一根的乘法阶表、边际价格和分圆块扫描。先选择较大的开放指数，按 Euler 内部、外部及赋值量分支。每个试验保存根与指数的精确覆盖表及首个未闭合分支。某个赋值区间被排除后，只有该指数全部 Euler 分支完成时才计入证书。
3. **测试能覆盖多指数的统一证书。** 对相同分圆因子或强制素数的指数集合，先证明统一的必要整除，再给合法指数的有限表、可验证的单调尾界或有理对偶。将实际指数与集合证书逐项对应，取并集后回填分片。一个小批次先测证书生成耗时、单核重放耗时、峰值内存和净闭合量，再决定扩大哪条路线。
4. **完成全覆盖并实测 72 小时目标。** 审计器应再生成 3,072 个规范分片，检查根顺序、互素类证书和各分片的覆盖。开放项归零后固定代码、输入和硬件，记录证书生成与独立复验各自的用时、峰值内存及恢复开销。判定 72 小时目标以一次完整可复现的运行作为依据。

已验收判据及证明入口见 [总证明](Proof2400.md)。
